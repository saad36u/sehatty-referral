# باك-إند تدريبي (محاكاة Kobo — بدون قاعدة بيانات)

مشروع تدريبي للفرونت/الباك. لا يوجد قاعدة بيانات حقيقية؛ يتم محاكاة بيانات مشروع
KoboToolbox من ملف [`kobo_data.json`](kobo_data.json). لا يوجد أي اتصال بموقع خارجي.

## التشغيل

```bash
node server/server.js
```

ثم افتح المتصفح على:

- الصفحة الرئيسية: <http://localhost:3000/>
- تسجيل الدخول: <http://localhost:3000/citizen/login/>

> مهم: يجب فتح الصفحات عبر السيرفر (`http://localhost:3000`) وليس بفتح ملف
> `index.html` مباشرة، لأن طلبات AJAX تحتاج للباك-إند.

## المسارات (Endpoints)

| الطريقة | المسار | الوظيفة |
|---|---|---|
| POST | `/citizen/login` | التحقق من الهوية + كلمة المرور، وإنشاء جلسة |
| GET | `/citizen/result` | بيانات التحويلة للمستخدم الحالي (حسب الجلسة) |
| GET | `/admin/patient-referral-profile` | الإحصائيات العامة |
| GET | `/citizen/logout` | إنهاء الجلسة |

## عند الدخول تُعرض للمستخدم

الاسم • رقم الجوال • التخصص • تاريخ التحويلة • حالة الطلب — في صفحة
`/citizen/citizen/referral/` (محمية: لا يمكن فتحها بدون تسجيل دخول).

## إضافة/تعديل بيانات

عدّل `submissions` داخل [`kobo_data.json`](kobo_data.json) فقط — لا حاجة لإعادة تشغيل
منطق، لكن يجب إعادة تشغيل السيرفر (يُحمَّل الملف عند كل طلب فتُلتقط التعديلات مباشرة).
